# Task Outcome Signals

Automatic log of task outcomes. Captured when a task goes differently than expected.
Used to surface patterns and feed the Warm tier.

**Format:** One entry per notable task. Only captures ⚠️ and ❌ outcomes (expected outcomes generate no signal).
